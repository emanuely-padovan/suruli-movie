# SURULI Movies - ಸುರುಳಿ

O "Suruli Movies" é um sorteador de filmes, onde o usuário coloca os filmes que tem interese e então o sistema sorteia uma das obras  para ele assistir.
O projeto pretende simplificar a vida de pessoas indecisas que não conseguem escolher o que assistir, ou que "procrastinam" obras para ver por não conseguirem decidir.
